# Guess the Number

Консольная игра на .NET 10: игрок угадывает число в заданном диапазоне и получает подсказки «больше»/«меньше».

## Возможности

- уровни сложности: лёгкий (10 попыток), средний (8), сложный (5);
- пользовательский диапазон от 1 до 1 000 000;
- статистика побед, поражений, среднего и лучшего результата сохраняется в `statistics.json`;
- доменная модель уведомляет подписчиков о попытках через событие `GuessMade`.

## Запуск

```bash
dotnet run --project GuessTheNumber.View
```

Во время игры введите число или `q` для выхода. Пустой ввод завершает текущую игру.
